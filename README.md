1. Цель работы
Изучить обобщённые типы Java (Generics), типовые параметры, ограничения и маски типов. Научиться создавать универсальные методы, которые обрабатывают коллекции разных типов с помощью передаваемых объектов и интерфейсов.
2. Постановка задачи
В соответствии с вариантом 3 необходимо выполнить: задание 1 — пункты 1 и 2; задание 2 — пункт 3; задание 3 — пункты 1, 2, 3 и 4. Все решения размещаются в одном проекте, но в разных классах. В главном методе main демонстрируется работа классов и методов. Ввод с клавиатуры не используется: для демонстрации работы методов в программе заданы готовые тестовые значения.
3. Используемые средства Java
T, P, R — типовые параметры обобщённых классов и методов.
List<T> и ArrayList<T> — список элементов заданного типа.
Map<K, V> и HashMap<K, V> — хранение значений по ключу; используется для группировки строк по длине.
Set<T> и HashSet<T> — коллекция без повторяющихся элементов.
Интерфейсы Transformer, PredicateRule, Reducer, ResultFactory и ResultWriter описывают действия, передаваемые универсальным методам.
Конструкции implements и @Override используются для реализации интерфейсов и переопределения методов.
4. Описание реализации
4.1. Задание 1.1. Обобщённая коробка
Создан класс Box<T>, который хранит одно значение типа T. Метод put(T value) помещает объект в коробку, но сначала проверяет, свободна ли она. Если коробка уже заполнена, выбрасывается IllegalStateException. Метод take() возвращает сохранённое значение и присваивает полю null. Метод isEmpty() проверяет заполненность. В main создаётся Box<Integer>, в него записывается введённое с клавиатуры число, после чего значение извлекается через отдельный метод showBox().
4.2. Задание 1.2. Без null
Создан неизменяемый класс Storage<T>. Поле value объявлено final и задаётся только в конструкторе. Метод getOrElse(T alternative) возвращает сохранённый объект, если он не равен null, иначе возвращает альтернативное значение. Проверяются четыре случая из условия: null и 99 для Integer, null и hello для String.
4.3. Задание 2.3. Начало отсчёта
Создан класс Point3D с координатами x, y и z. Метод putPoint принимает Box<? super Point3D>. Такая маска позволяет передавать коробки, тип которых является Point3D или его родительским типом (например, Box<Object>). Метод помещает в коробку новую трёхмерную точку. Для демонстрации используется точка с координатами (1, 2, 3).
4.4. Задание 3.1. Функция
Интерфейс Transformer<T, P> содержит единственный метод apply(T value), возвращающий P. Универсальный метод map принимает список T и преобразователь, затем создаёт новый список P. Проверены три варианта: получение длин строк, замена отрицательных чисел их модулями и получение максимумов исходных массивов целых чисел.
4.5. Задание 3.2. Фильтр
Интерфейс PredicateRule<T> содержит метод test(T value), возвращающий boolean. Метод filter проходит по исходному списку и добавляет в новый список только элементы, прошедшие проверку. Выполнены три проверки: строки длиной не менее трёх символов; неположительные числа; массивы, в которых нет положительных элементов.
4.6. Задание 3.3. Сокращение
Интерфейс Reducer<T> описывает объединение двух значений одного типа. Метод reduce принимает исходный список, начальное значение identity и объект Reducer. Начальное значение позволяет корректно обработать пустой список: для пустого списка возвращается identity, поэтому метод не возвращает null и не обращается к отсутствующему первому элементу. Проверены объединение строк, сумма чисел и подсчёт общего количества элементов во вложенных списках. Для последнего примера сначала получаются размеры внутренних списков методом map, затем они суммируются.
4.7. Задание 3.4. Коллекционирование
Интерфейс ResultFactory<R> создаёт результирующую структуру, а ResultWriter<R, T> определяет, как добавить в неё один исходный элемент. Универсальный метод collect не зависит от конкретного вида результата. Реализованы три случая: разделение чисел на положительные и отрицательные подсписки; группировка строк по длине с помощью Map<Integer, List<String>>; получение множества уникальных строк с помощью Set<String>.
5. Структура проекта
Проект состоит из отдельных файлов: Box.java, Storage.java, Point3D.java, Task21BoxAndStorage.java, Task23PointInBox.java, Task31Function.java, Task32Filter.java, Task33Reduce.java, Task34Collect.java, Main.java и интерфейсов Transformer.java, PredicateRule.java, Reducer.java, ResultFactory.java, ResultWriter.java. Главный класс Main содержит метод main и последовательно демонстрирует все пункты варианта.

7. Вывод
В ходе лабораторной работы были изучены обобщённые классы и методы Java. Созданы классы с типовыми параметрами, применена маска ? super, реализованы универсальные методы преобразования, фильтрации, сокращения и формирования коллекций. Проверена работа методов на строках, числах, массивах и вложенных списках. Использование Generics позволяет повторно применять один алгоритм к разным типам данных и уменьшает необходимость явного приведения типов.

Из корневой папки проекта выполнить команды:
javac -encoding UTF-8 -d out src/*.java
java -cp out Main
При запуске программа автоматически выполняет все демонстрационные примеры и выводит результаты в консоль.
